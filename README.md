# Pickly

Exercices du parcours [Git et GitHub - Collaborer sur un projet](https://ephec.dev/parcours/git-et-github-collaborer-sur-un-projet) (EPHEC.dev), reprogrammés en JavaScript (Node.js).

| Fichier | Exercice |
| --- | --- |
| `exercices/01-status-short.js` | Lire `git status --short` |
| `exercices/02-hash-object.js` | Calculer l'identifiant d'un blob |
| `exercices/03-git-log.js` | Reprogrammer `git log` |
| `exercices/04-branches.js` | Simuler les branches |
| `exercices/05-type-de-fusion.js` | Quel type de fusion ? |
| `exercices/06-fusion-trois-points.js` | Fusion à trois points ligne par ligne |
| `exercices/07-rebase.js` | Les commits rejoués par un rebase |
| `exercices/08-ahead-behind.js` | En avance ou en retard ? |
| `exercices/09-messages-de-commit.js` | Vérifier des messages de commit |
| `exercices/10-gitignore.js` | Reprogrammer `.gitignore` |

## Utilisation

Chaque programme lit l'entrée standard :

```bash
node exercices/02-hash-object.js < exemples/02-hash-object.in
```

Lancer tous les exemples :

```bash
npm test
```
